  <files>main.go, main_test.go, README.md</files>
  <behavior>
    - `[]`, `"a b c\n"` → stdout `"lines=1 words=3\n"`, exit 0
    - `["-top","0"]`, same input → same output, exit 0
    - `["-top","2"]`, `"b a B c\n"` → `"lines=1 words=4\nb 2\na 1\n"`, exit 0
    - `["-top","3"]`, `""` → `"lines=0 words=0\n"`, exit 0
    - `["-top","-1"]`, `"a\n"` → empty stdout, stderr contains `tally: -top must be >= 0`, exit 2
    - `["-bogus"]`, `"a\n"` → empty stdout, non-empty stderr (flag usage), exit 2
  </behavior>
  <action>
Write `TestRun` first (table-driven; assert stdout, stderr where listed, and exit code). Then add `func run(args []string, in io.Reader, out, errOut io.Writer) int`. `main` becomes `os.Exit(run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr))`. Parse `-top` (int, default 0) with `flag.NewFlagSet` using `flag.ContinueOnError` and `fs.SetOutput(errOut)` so parse errors and usage text go to errOut, never `out`; a parse failure returns 2. Reject N<0 with `tally: -top must be >= 0` on errOut and return 2. Call `scan`, print the counts line, then for N>0 print each `Top` entry as `fmt.Fprintf(out, "%s %d\n", ...)`. A scan error prints `tally: <err>` on errOut and returns 1. Add a `-top N` example to the README usage section.
  </action>
