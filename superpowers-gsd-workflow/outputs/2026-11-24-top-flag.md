# tally `-top N` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 tally 加 `-top N` 标志，在行/词数之后输出前 N 个高频词。

**Architecture:** 新增内部 `scan` 一遍扫描同时得出 `Counts` 与词频 map；`Count` 变为其包装（签名与 `Counts` 不变）；新增纯函数 `Top` 排序截取；`main` 解析标志并打印。

**Tech Stack:** Go 1.22，仅标准库（`sort`、`strings`、`flag`）。

**Spec:** `docs/superpowers/specs/2026-11-24-top-flag-design.md`

## Global Constraints

- 全部代码在 `main.go`，测试在 `main_test.go`（沿用现有结构），测试用表驱动 `[]struct{...}` + `t.Run`。
- 注释/错误提示用英文（匹配现有代码库风格），错误前缀 `tally:`。
- 词 = `strings.Fields` 的结果，统计前 `strings.ToLower`；不剥离标点。
- 排序：次数降序，次数相同按词字母序升序。
- 输出格式：`word count`（单空格）；`-top 0`（默认）输出与现在逐字节一致：`lines=%d words=%d\n`。
- 负数 N：stderr 输出 `tally: -top must be >= 0`，退出码 2。
- N 大于不同词数：输出全部。
- 不改 `Count` 签名、不改 `Counts` 字段（保持可 `==` 比较）。

## Review Focus

- 大小写混合 `"The the THE"` → 一条 `the 3`。
- 同次数并列 `"b a c"` → `a 1`、`b 1`、`c 1`。
- 空输入且 `-top 3` → 只有 `lines=0 words=0`，无多余行。
- N 超过不同词数 → 全部输出，不 panic。
- 负数 N → 退出码 2 且 stdout 无输出。

### Task 1: 词频统计与排序

**Files:**
- Modify: `main.go`（`Count` 之后）
- Test: `main_test.go`

**Interfaces:**
- Produces:
  - `type WordFreq struct { Word string; N int }`
  - `func scan(r io.Reader) (Counts, map[string]int, error)`
  - `func Top(freq map[string]int, n int) []WordFreq`（`n <= 0` 返回 nil；`n` 超过长度返回全部）
  - `Count(r io.Reader) (Counts, error)` 行为不变，改为调用 `scan`。

- [ ] **Step 1: 写失败测试** `TestTop`（表驱动，输入经 `scan` 得 freq 再 `Top`）：
  - `"The the THE\n", 3` → `[{the 3}]`
  - `"b a c\n", 2` → `[{a 1} {b 1}]`
  - `"a a b\n", 10` → `[{a 2} {b 1}]`
  - `"", 3` → 长度 0
  - `"a b\n", 0` → 长度 0
  - 同时断言 `scan` 返回的 `Counts` 等于 `Count` 对同一输入的返回（`{Lines:1, Words:3}` 对 `"The the THE\n"`）。
- [ ] **Step 2: 运行确认失败**：`go test ./... -run TestTop` → 预期编译失败（`scan`/`Top` 未定义）。
- [ ] **Step 3: 实现** 上述签名于 `main.go`；`Top` 先收集成切片，用 `sort.Slice` 按（次数降序，词升序）排序后截断到 n；`Count` 调 `scan` 丢弃 map。
- [ ] **Step 4: 运行确认通过**：`go test ./...` → 全部 PASS（含原 `TestCount`）。
- [ ] **Step 5: 提交**：`git add main.go main_test.go && git commit -m "feat: 增加词频统计与 Top 排序"`

### Task 2: `-top` 标志与输出

**Files:**
- Modify: `main.go` 的 `main`
- Modify: `README.md`（用法段加 `-top N` 示例）
- Test: `main_test.go`

**Interfaces:**
- Consumes: `scan`、`Top`、`WordFreq`（Task 1）。
- Produces: `func run(args []string, in io.Reader, out, errOut io.Writer) int`，返回退出码；`main` 仅 `os.Exit(run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr))`。使用 `flag.NewFlagSet` 解析 `-top`（`int`，默认 0）。

- [ ] **Step 1: 写失败测试** `TestRun`（表驱动，断言 stdout 字符串与退出码）：
  - `args=[]`, `"a b c\n"` → `"lines=1 words=3\n"`, 0（默认输出不变）
  - `["-top","0"]`, 同上 → 同上
  - `["-top","2"]`, `"b a B c\n"` → `"lines=1 words=4\nb 2\na 1\n"`, 0
  - `["-top","3"]`, `""` → `"lines=0 words=0\n"`, 0
  - `["-top","-1"]`, `"a\n"` → stdout 为空，stderr 含 `tally: -top must be >= 0`，退出码 2
- [ ] **Step 2: 运行确认失败**：`go test ./... -run TestRun` → 编译失败（`run` 未定义）。
- [ ] **Step 3: 实现 `run`**：解析标志（解析失败返回 2）；校验 N；`scan` 读入；打印原统计行；`N>0` 时对 `Top` 结果逐行 `fmt.Fprintf(out, "%s %d\n", ...)`；扫描错误输出 `tally: <err>` 返回 1。更新 `main` 与 README。
- [ ] **Step 4: 运行确认通过**：`go test ./...` → PASS；手动 `printf 'b a B c\n' | go run . -top 2` 输出 `lines=1 words=4`、`b 2`、`a 1`。
- [ ] **Step 5: 提交**：`git add main.go main_test.go README.md && git commit -m "feat: 增加 -top N 标志"`
